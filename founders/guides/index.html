Questions about the guides

Who are these speaking guides for?

They are for founders and business owners who want to pitch, present and answer questions more clearly, including shy founders and people speaking English as a second language.

Which guide should I start with?

If you have a pitch coming up, start with practising an investor pitch alone. If you avoid speaking, start with the guide for shy founders. If people ask you to repeat yourself, start with speaking slower and more clearly.

Do I need an account to read the guides?

No. You can read every guide without creating an account.

How is Founder Rehearsal different from the guides?

Founder Rehearsal is a private speaking practice platform for founders, customised to each founder's needs. The guides give general methods; modules are built around your own goal, subject and material.
